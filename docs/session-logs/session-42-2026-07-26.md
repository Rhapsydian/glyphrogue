## Key decisions

- **Live, user-driven publish.** This environment's npm wasn't
  authenticated, and publishing to a public registry is an external,
  irreversible action outside what should happen unilaterally regardless
  — the user ran `npm login`/`npm publish` themselves in their own
  terminal for all four packages, with exact commands handed over each
  time and results verified via unauthenticated `npm view` reads.
- **The `@glyphrogue` npm org didn't exist.** First publish attempt
  404'd ("Scope not found") — the user's npm username is `rhapsydian`,
  not `glyphrogue`, so the scope needed a real org, not an
  automatic personal-scope match. Created live rather than renaming the
  packages (which would've meant touching hundreds of `@glyphrogue/*`
  references across the whole codebase for a cosmetic reason).
- **MIT license, repo-wide** — nothing had a license before this session.
- **Zero-dependency CLI.** `node:readline/promises` for the one prompt,
  plain `replaceAll` token substitution — matches `cli.md`'s own
  decisions and this project's existing no-unnecessary-dependencies
  convention (`mods.js`'s hand-rolled semver, etc.).
- **CSS-generic monospace starter font**, not a bundled binary. Real
  metrics (`unitsPerEm`/`ascender`/`descender`) registered via
  `registerFontSource` — `fontSources.js`'s default calibration is
  metrics-based, so this is a genuine, already-calibrated font source per
  `cli.md`'s starter bar, not a placeholder standing in for a real one.
  Avoided downloading any external font file.
- **Static-template rendering for the starter room**, not a live ECS
  query. The scaffold renders `starter-room.json`'s template directly;
  `instantiateZoneContent` still creates real ECS entities (proving the
  plugin/entity-type system works), but wiring live rendering to world
  state (camera, `renderLayers`, entity queries) is real gameplay's job,
  not this scaffold's — matches the "zero required edits, nothing
  advanced" bar without needing an input loop.
- **Documentation audit findings**: fixed everything with an objective,
  factual answer (13 items — stale claims, dangling cross-references,
  a placeholder README, a wrong test count I introduced myself). Two
  findings needed a judgment call rather than a mechanical fix, resolved
  live: `glossary.md`'s "Region" term collision (kept both senses,
  disambiguated, rather than renaming load-bearing code) and a
  session-29/30 test-count arithmetic gap in `BACKLOG.md` (left as an
  acknowledged discrepancy with a footnote rather than guessing at a
  correction for something that predates this session).
